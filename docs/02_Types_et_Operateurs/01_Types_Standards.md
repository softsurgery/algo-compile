# 1. Types Standards de Données

Le langage algorithmique prend en charge les types scalaires fondamentaux suivants :

---

## Tableau Récapitulatif

| Type Algorithmique | Type Python | Exemples de Valeurs | Description |
|---|---|---|---|
| **Entier** | `int` | `-5`, `0`, `42` | Nombres entiers relatifs (positifs ou négatifs). |
| **Réel** | `float` | `3.14`, `-0.05`, `2.0` | Nombres à virgule flottante. |
| **Booléen** | `bool` | `Vrai`, `Faux` | Valeurs de vérité logiques. |
| **Caractère** | `str` (len 1) | `'a'`, `'Z'`, `'@'` | Un caractère unique entre apostrophes. |
| **Chaîne** | `str` | `"Algorithme"`, `"2025"` | Séquence ordonnée de caractères entre guillemets. |

---

## Remarques Spéciales

1. **Constantes Booléennes** :
   - Écrites `Vrai` ou `Faux` (avec majuscule ou minuscule acceptée par le compilateur).
2. **Délimiteurs de texte** :
   - Les chaînes sont délimitées par des guillemets doubles `"` (ex: `"Bonjour"`).
   - Les caractères peuvent être délimités par des apostrophes `'` ou guillemets.
3. **Tableaux de scalaires** :
   - La déclaration d'un vecteur ou d'une matrice précise toujours son type de base (ex: `Tableau de 100 Entier`).
