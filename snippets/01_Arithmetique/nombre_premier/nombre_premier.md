# Détection de Nombre Premier

## Description
Vérifie si un entier positif `n` est premier à l'aide de la fonction `EstPremier(n: Entier) : Booléen`, en testant les diviseurs impairs jusqu'à $\sqrt{n}$ (`d * d <= n`).

## Concepts Abordés
- Fonction booléenne (`EstPremier`)
- Opérateur modulo (`Mod`)
- Boucle `Tant que` avec arrêt anticipé
