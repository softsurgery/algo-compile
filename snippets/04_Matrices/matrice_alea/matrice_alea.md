# Matrice Aléatoire 2D

## Description
Génération et manipulation d'un tableau à deux dimensions (matrice N x M) rempli de valeurs aléatoires entières via la fonction standard `Aléa(min, max)`.

## Points Clés
- Déclaration d'un tableau 2D dans le TDO : `M : Tableau de [10, 10] Entier`
- Boucles imbriquées `Pour i` (lignes) et `Pour j` (colonnes)
- Affichage formaté ligne par ligne avec `Ecrire` et saut de ligne `Ecrire_nl`
